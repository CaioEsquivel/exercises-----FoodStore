

# FoodStore 🍔

Cardápio interativo desenvolvido com **HTML, CSS e JavaScript**. Exibe produtos de diferentes categorias (hambúrgueres, pizzas, batatas e hot dogs) com nome, imagem, descrição e preço. Permite busca, filtro por categoria e exibição detalhada com cálculo automático de taxa. Totalmente responsivo para desktop e celular.

---

## Funcionalidades

* Exibição dinâmica de produtos em **cards**
* **Filtro por categoria** (hambúrguer, pizza, batata, hot-dog e todos)
* **Busca interativa** por nome ou tipo de produto
* Mensagem de aviso para **produtos não encontrados**
* **Modal detalhado** ao clicar em um produto, exibindo preço, taxa (30%) e total
* **Animações suaves** na abertura e fechamento do modal
* Layout **responsivo** para desktop e dispositivos móveis

---

## Tecnologias

* **HTML5**
* **CSS3** (Flexbox e Media Queries)
* **JavaScript** (DOM, eventos e arrays)

---

## Como usar

1. Clone o repositório
2. Abra `index.html` em seu navegador
3. Navegue entre as **categorias** ou use a **busca** para encontrar produtos
4. Clique em um produto para ver **detalhes e o preço total com taxa**
